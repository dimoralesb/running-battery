# Kavanagh2024: Generic vs relative speed thresholds in EPL matches
Citation: Kavanagh R, Di Michele R, Oliveira R, McDaid K, Rhodes D, Morgans R. The relationships between distances covered above generic and relative speed thresholds by male soccer players in English Premier League matches across two competitive seasons. The effects of positional demands and possession. Biol Sport. 2024;41(4):77-86. doi:10.5114/biolsport.2024.135416 (PMC11474994)
Type: match study (single club)
Context: English Premier League, **one club**, seasons 2019/20 and 2020/21 (COVID seasons, partly behind closed doors). 16 outfield players (7 defenders, 6 midfielders, 3 forwards), age 27.8 ± 3.5 y. 38 league matches per season (19 home + 19 away). Inclusion: >= 75 min on pitch, >= 8 such matches, data in both seasons. 630 player-match observations (median 40.5 per player, range 8-74). Optical tracking: Second Spectrum, semi-automated HD cameras, 25 Hz (p.78). Distances for < 90 min were extrapolated to 90 min (p.79).
Evidence strength: low-medium. Correct design (repeated-measures correlation, mixed models), but 16 players from one club, only 3 position groups, and only 3 forwards.

**Positional differences (mixed models, ES = difference / between-subject SD) (p.80-81)**
- Whole match: Mid > Def for TD (ES 1.91), HSRD (1.33), HIRD (1.59), > MAS (1.36), > 30% ASR (1.19). Mid > Fwd for TD (0.89) and > 85% PS (1.74). Fwd > Def for TD (1.01), HIRD (1.23), > MAS (1.65). **Sprint distance did not differ between positions for the whole match.**
- TIP: Fwd > Def and > Mid for HSRD (2.13; 1.28), HIRD (2.17; 1.07), sprint (1.80; 1.37), > MAS (2.26; 1.36), > 30% ASR (2.14; 1.47).
- OTIP: Mid > Def for TD (1.53), HSRD (1.20), HIRD (1.32), > MAS (1.27). Mid > Fwd for TD (1.96), HSRD (2.09), HIRD (2.03), > MAS (1.93), > 30% ASR (2.14), > 85% PS (2.43). Def > Fwd for > 30% ASR (1.25), > 85% PS (1.44).
- BOP: Mid > Def for TD (1.61), > MAS (2.04), > 30% ASR (2.18).
- Discrepancy example (p.84): in TIP, forwards had more sprint distance (> 7 m/s) than midfielders, but not more distance > 85% PS. In OTIP, forwards had less > 85% PS than defenders and midfielders, but sprint distance did not differ. The reason is that position groups have different peak speeds.

**Recommendation (p.83-85)**: > 30% ASR is redundant if HSRD is monitored (r = 0.98, because the 30% ASR threshold of 5.76 m/s sits close to 5.5 m/s, with little spread between players). > MAS and especially > 85% PS add information, because they are not perfectly correlated with any generic metric. A relative threshold for sprinting (% of PS) "may provide different, and arguably more accurate" load information. Conclusion: relative thresholds expose players to "more high-intensity distance" than generic ones.

## Equations
MAS from the 1200 m Bronco shuttle with a turn correction (p.79; checked against PDF):
$$ \mathrm{MAS} = \frac{1200}{T - 20.3} $$
- MAS: maximal aerobic speed, m/s
- T: time to complete 1200 m (5 x 20-40-60 m shuttles), s
- 20.3 s: correction for turns (0.7 s per turn, 29 turns)

Anaerobic speed reserve (p.79; checked against PDF):
$$ \mathrm{ASR} = \mathrm{PS} - \mathrm{MAS} $$
- PS: season-max peak match speed, m/s

30% ASR threshold (my reading of the text "weighted MAS value and the MSS ... using 70% and 30%", p.79):
$$ v_{30\%ASR} = \mathrm{MAS} + 0.3\,\mathrm{ASR} = 0.7\,\mathrm{MAS} + 0.3\,\mathrm{PS} $$
With the group means this gives 0.7(4.63) + 0.3(9.53) = 6.10 m/s, but the paper reports 5.76 ± 0.1 m/s (p.81). **The formula and the reported value do not agree.** The exact formula used is unclear.

85% PS threshold: $v_{85} = 0.85\,\mathrm{PS}$ (checks out: 0.85 x 9.53 = 8.10 m/s).

## Limitations
- One club, 16 players, 3 forwards. Position groups merge CB with FB and CM with wide players.
- 2019/20-2020/21 includes COVID behind-closed-doors matches and a 3-month break.
- Peak speed is the season max from matches only. It may underestimate true maximal sprint speed, and it is updated during the season, so the threshold moves.
- MAS comes from one pre-season field test.
- No acceleration data, no internal load, no context (score, opponent, venue) (p.84).
- Only correlations. No R², no Bland-Altman bias, no regression equations linking generic to relative distances.
- Formula/value mismatch for the 30% ASR threshold (see above).
- Per-90 extrapolation for players with < 90 min, but matches averaged 95.5 min, so "whole match" totals are partly per-90 and partly per-real-time.

## Use in Second Wind
- Simulator: per-position (D/M/F) calibration targets for Second Spectrum 25 Hz: TD, HSRD, HIRD, sprint, split by possession phase (Tables 2 and 4). **Top speed targets**: season-max PS about 9.4-9.8 m/s (33.7-35.4 km/h), SD 0.3-0.4 m/s between players. Use the phase-time split (TIP 23%, OTIP 32%, BOP 45% of 95.5 min) for the simulator's phase durations. Note that OTIP running intensity > TIP intensity for D and M.
- Fatigue estimator: supports using **% of each player's own peak speed** (e.g. 85% PS) for sprint-type load and for "near top speed" detection. For HSR, generic 5.5 m/s gives almost the same information as a 30% ASR threshold in elite players. So use generic 5.5 m/s for HSR, but a relative threshold (85% PS) for high-end efforts. CS / D' are not addressed. MAS (4.6 m/s) is a rough proxy for critical speed (CS is usually a bit below MAS/vVO2max).
- Agents / claims: "Forwards sprint more than defenders" is only true in possession. Over the whole match, sprint distance did not differ between groups in this sample. "Relative thresholds always change the picture" is overstated: for HSR, r = 0.98.
- Overlay / UI: show "% of personal top speed" rather than raw km/h for sprint efforts.

## Ideas or questions it raised
- READING_LIST describes it correctly but leaves out that it is **one club, n = 16**, not a league-wide study. It also gives no recommendation strength. The paper reports no R² or bias, so the evidence for "use relative thresholds" is weak: correlation only.
- The caller's question "which % of peak speed": only 85% PS is used. There are no other % bands.
- Matches the 85% PS idea in our plan (rolling HSR vs the player's own peak). Our estimator could use 85% of the hidden true top speed in the simulator and 85% of the observed season-max in real data. The observed max will underestimate the true max.
- BOP time of 45% suggests a long ball-out-of-play time. The simulator should include stoppages (very low running, ~63-68 m/min) so recovery happens during BOP.
